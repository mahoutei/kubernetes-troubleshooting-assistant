# RAG over Kubernetes Docs — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a deployed, citation-backed RAG service over pinned Kubernetes docs with reproducible retrieval/generation evals and ablations.

**Architecture:** Markdown docs → heading-aware chunks → local BGE embeddings + BM25 → reciprocal rank fusion → cross-encoder rerank → free-tier LLM with citation-enforcing prompt → FastAPI + minimal web UI. Evals are a separate harness over a 60-question, human-certified gold set.

**Tech Stack:** Python 3.12, uv 0.13.6, FastAPI, LanceDB, rank_bm25, sentence-transformers, OpenAI-compatible free APIs (Groq/Gemini), pytest, Docker, GitHub Actions, HF Spaces.

**Spec:** `docs/superpowers/specs/2026-10-29-llm-portfolio-design.md`

**Status of this revision:** Tasks 1–8 and the eval harness in Task 9 are implemented on branch `feat/rag-eval` (`ce0248b`, plus two post-baseline code changes: `d209300` makes the certificate tests certificate-state independent, and `93b4297` batches embeddings at 64, adds `Embedder(model_name, show_progress=False)`, and logs index-build phases/elapsed time). This plan was re-reconciled against the implemented branch: the embedded code blocks below are the implemented files, not the original pre-implementation sketches. Task 9's judge/runner/calibration and Task 10's summarizer/ablation script are implemented too; the embedded blocks mirror them. The runner/judge interfaces are stable; remaining code changes are test-count/status updates only.

## Global Constraints

- Python `>=3.12,<3.13`; manage with `uv` **0.13.6**. The `dev` dependency group installs by default, so the command is `uv sync`; uv 0.13.6 has no `--dev` flag on `sync` (use `uv sync --no-dev` only for the runtime image).
- Default LLM provider: Groq `openai/gpt-oss-120b` (the previous Groq flagship was retired on 2026-08-16; do not reintroduce it). Optional second endpoint: Gemini `gemini-2.5-flash`. A cross-family judge defaults to `gemini-2.5-flash`.
- Docker is **not installed on this machine**; the image build in Task 11 is verified in CI/on the deploy host, not locally.
- Pinned docs commit: `47132eb5367cfdcba0a3b33a0b3ffc81185bd7e8` (branch `release-1.34`).
- Corpus root inside the tarball: `website-47132eb5367cfdcba0a3b33a0b3ffc81185bd7e8/content/en/docs`.
- Include only `concepts/`, `tasks/`, `tutorials/`, `reference/`; exclude `reference/generated/`, `contribute/`, `home/`, `setup/`.
- Chunk target default 500 tokens, 15% overlap; never split a fenced code block, and never treat a `#` line inside a fence as a heading.
- No API key may be required for unit tests or CI.
- No published number may be hand-written; it must come from a committed results JSON.
- No code copied from unlicensed repos. Adapted code gets an entry in `ATTRIBUTIONS.md`.
- Commit after every task.

## Review Focus

- **Question longer than 500 chars or empty:** API returns 422, never a 500.
- **LLM returns citations that do not exist (`[9]` with 5 chunks):** dropped, not rendered as a broken link.
- **Retrieved context is insufficient:** system refuses instead of hallucinating; refusal is scored (`refusal_accuracy`, `over_refusal_rate`).
- **Both LLM providers fail:** `LLMError` is raised by generation and `/ask` returns 503, never a stack trace.
- **Docs tarball contains a path-traversal entry:** extraction rejects it.
- **Docker/Spaces has no API key:** `/health` works and `/ask` returns a clear 503/offline answer, not a stack trace.
- **Code fence contains blank lines or a `#` comment line:** chunker keeps it intact and does not split it into a heading.
- **Gold set has duplicate IDs or wrong split counts:** validator fails before an eval runs.
- **Test split run before certification:** `run_eval.py --split test` refuses until `CERTIFICATION.md` has Reviewer/Date/Notes.
- **Retriever asked for 20 results:** `retrieve(..., top_k=20)` returns 20 (dense-only included), and recall is document-level so it can never exceed 1.0.

# src/rag/config.py
from __future__ import annotations

import os
from dataclasses import dataclass, field

DOCS_COMMIT = "47132eb5367cfdcba0a3b33a0b3ffc81185bd7e8"
DOCS_URL = f"https://github.com/kubernetes/website/archive/{DOCS_COMMIT}.tar.gz"
DOCS_PREFIX = f"website-{DOCS_COMMIT}/content/en/docs"

# The previous Groq flagship model was retired by Groq on 2026-08-16; gpt-oss-120b
# is the documented replacement. Keep provider model IDs here, not inline.
PROVIDER_DEFAULTS = {
    "groq": {
        "model": "openai/gpt-oss-120b",
        "base_url": "https://api.groq.com/openai/v1",
        "key_env": "GROQ_API_KEY",
    },
    "gemini": {
        "model": "gemini-2.5-flash",
        "base_url": "https://generativelanguage.googleapis.com/v1beta/openai/",
        "key_env": "GEMINI_API_KEY",
    },
}


@dataclass(frozen=True)
class Settings:
    docs_url: str = DOCS_URL
    docs_prefix: str = DOCS_PREFIX
    docs_dir: str = "data/docs"
    index_dir: str = "data/index"
    chunk_tokens: int = 500
    chunk_overlap: float = 0.15
    embed_model: str = "BAAI/bge-small-en-v1.5"
    rerank_model: str = "BAAI/bge-reranker-base"
    top_k_dense: int = 50
    top_k_bm25: int = 50
    top_k_rerank: int = 20
    top_k_context: int = 5
    rrf_k: int = 60
    llm_provider: str = "groq"
    llm_model: str = PROVIDER_DEFAULTS["groq"]["model"]
    llm_base_url: str = PROVIDER_DEFAULTS["groq"]["base_url"]
    llm_api_key: str | None = field(default=None, repr=False)
    llm_fallback_provider: str | None = None
    llm_fallback_model: str | None = None
    llm_fallback_base_url: str | None = None
    llm_fallback_api_key: str | None = field(default=None, repr=False)
    offline: bool = False
    max_answer_tokens: int = 600

    def __post_init__(self) -> None:
        if not 100 <= self.chunk_tokens <= 2000:
            raise ValueError("chunk_tokens must be between 100 and 2000")
        if not 0.0 <= self.chunk_overlap < 1.0:
            raise ValueError("chunk_overlap must be in [0, 1)")
        if self.top_k_context > self.top_k_rerank:
            raise ValueError("top_k_context cannot exceed top_k_rerank")
        if self.llm_provider not in PROVIDER_DEFAULTS:
            raise ValueError(f"unknown llm_provider: {self.llm_provider}")
        if (
            self.llm_fallback_provider is not None
            and self.llm_fallback_provider not in PROVIDER_DEFAULTS
        ):
            raise ValueError(f"unknown llm_fallback_provider: {self.llm_fallback_provider}")
        if self.llm_fallback_provider == self.llm_provider:
            raise ValueError("llm_fallback_provider must differ from llm_provider")

    @classmethod
    def from_env(cls) -> Settings:
        provider = os.getenv("LLM_PROVIDER", "groq").lower()
        if provider not in PROVIDER_DEFAULTS:
            raise ValueError(f"LLM_PROVIDER must be one of {sorted(PROVIDER_DEFAULTS)}")
        defaults = PROVIDER_DEFAULTS[provider]

        fallback = os.getenv("LLM_FALLBACK_PROVIDER", "gemini").strip().lower()
        if fallback in {"", "none", "off"}:
            fallback = None
        if fallback is not None and fallback not in PROVIDER_DEFAULTS:
            raise ValueError(
                f"LLM_FALLBACK_PROVIDER must be one of {sorted(PROVIDER_DEFAULTS)} or 'none'"
            )
        fallback_defaults = PROVIDER_DEFAULTS[fallback] if fallback else {}
        if fallback == provider:
            fallback = None

        return cls(
            docs_dir=os.getenv("RAG_DOCS_DIR", "data/docs"),
            index_dir=os.getenv("RAG_INDEX_DIR", "data/index"),
            llm_provider=provider,
            llm_model=os.getenv("LLM_MODEL", defaults["model"]),
            llm_base_url=os.getenv("LLM_BASE_URL", defaults["base_url"]),
            llm_api_key=os.getenv(defaults["key_env"]),
            llm_fallback_provider=fallback,
            llm_fallback_model=(
                os.getenv("LLM_FALLBACK_MODEL", fallback_defaults.get("model"))
                if fallback
                else None
            ),
            llm_fallback_base_url=(
                os.getenv("LLM_FALLBACK_BASE_URL", fallback_defaults.get("base_url"))
                if fallback
                else None
            ),
            llm_fallback_api_key=(
                os.getenv(fallback_defaults["key_env"]) if fallback else None
            ),
            offline=os.getenv("RAG_OFFLINE", "0") == "1",
        )

from rag.chunk import chunk_text, parse_markdown


def word_count(text: str) -> int:
    return len(text.split())

# src/rag/ingest.py
from __future__ import annotations

import tarfile
from collections.abc import Iterator
from pathlib import Path

import httpx

from rag.config import Settings

INCLUDE_PREFIXES = ("concepts/", "tasks/", "tutorials/", "reference/")
EXCLUDE_PREFIXES = ("reference/generated/",)


def _is_safe_member(name: str, dest: Path) -> bool:
    target = (dest / name).resolve()
    return str(target).startswith(str(dest.resolve()) + "/")


def extract_tarball(archive: Path, dest: Path) -> Path:
    dest.mkdir(parents=True, exist_ok=True)
    with tarfile.open(archive, "r:gz") as tf:
        for member in tf.getmembers():
            if not _is_safe_member(member.name, dest):
                raise ValueError(f"unsafe path in archive: {member.name}")
        tf.extractall(dest, filter="data")
    return dest


def download_and_extract(settings: Settings) -> Path:
    dest = Path(settings.docs_dir)
    marker = dest / ".complete"
    if marker.exists():
        return dest
    dest.mkdir(parents=True, exist_ok=True)
    archive = dest / "docs.tar.gz"
    with httpx.stream("GET", settings.docs_url, follow_redirects=True, timeout=120) as r:
        r.raise_for_status()
        with archive.open("wb") as f:
            for block in r.iter_bytes():
                f.write(block)
    extract_tarball(archive, dest)
    (dest / settings.docs_prefix).rename(dest / "content")
    marker.write_text("ok")
    archive.unlink(missing_ok=True)
    return dest


def iter_markdown(docs_root: Path) -> Iterator[Path]:
    content = docs_root / "content"
    for path in sorted(content.rglob("*.md")):
        rel = path.relative_to(content).as_posix()
        if not rel.startswith(INCLUDE_PREFIXES):

        if rel.startswith(EXCLUDE_PREFIXES):

# src/rag/chunk.py
from __future__ import annotations

import hashlib
import re
from collections.abc import Callable

from rag.models import Chunk

FRONTMATTER_RE = re.compile(r"\A---\s*\n(.*?)\n---\s*\n", re.DOTALL)
SHORTCODE_RE = re.compile(r"\{\{[<%].*?[>%]\}\}", re.DOTALL)
HEADING_RE = re.compile(r"^(#{1,6})\s+(.+?)\s*$", re.MULTILINE)


def _frontmatter(text: str) -> tuple[dict[str, str], str]:
    match = FRONTMATTER_RE.match(text)
    if not match:
        return {}, text
    meta: dict[str, str] = {}
    for line in match.group(1).splitlines():
        if ":" in line:
            key, value = line.split(":", 1)
            meta[key.strip()] = value.strip().strip('"').strip("'")
    return meta, text[match.end():]


def _slug(heading: str) -> str:
    slug = re.sub(r"[^a-z0-9\s-]", "", heading.lower())
    return re.sub(r"\s+", "-", slug.strip())


def _url(source_path: str, anchor_heading: str) -> str:
    rel = source_path.removesuffix(".md")
    rel = rel.replace("/_index", "").strip("/")
    base = f"https://kubernetes.io/docs/{rel}/"
    return f"{base}#{_slug(anchor_heading)}" if anchor_heading else base


def _split_blocks(text: str) -> list[str]:
    blocks: list[str] = []
    buf: list[str] = []
    in_fence = False
    for line in text.splitlines():
        if line.startswith("```"):
            in_fence = not in_fence
        if not in_fence and not line.strip():
            if buf:
                blocks.append("\n".join(buf).strip())
                buf = []
        else:
            buf.append(line)
    if buf:
        blocks.append("\n".join(buf).strip())
    return [b for b in blocks if b]


def _mask_fenced_lines(text: str) -> str:
    """Blank out fenced lines so heading scans ignore `#` comments in code."""
    masked: list[str] = []
    in_fence = False
    for line in text.splitlines(keepends=True):
        if line.startswith("```"):
            in_fence = not in_fence
        masked.append(re.sub(r"[^\n]", " ", line) if in_fence else line)
    return "".join(masked)


def chunk_text(
    text: str,
    max_tokens: int,
    overlap: float,
    count_tokens: Callable[[str], int],
) -> list[str]:
    blocks = _split_blocks(text)
    chunks: list[str] = []
    current: list[str] = []
    current_tokens = 0
    overlap_tokens = int(max_tokens * overlap)

    def flush() -> None:
        nonlocal current, current_tokens
        if current:
            chunks.append("\n\n".join(current))
        tail: list[str] = []
        tail_tokens = 0
        for block in reversed(current):
            if tail_tokens >= overlap_tokens:
                break
            tail.insert(0, block)
            tail_tokens += count_tokens(block)
        current = tail
        current_tokens = tail_tokens

    for block in blocks:
        tokens = count_tokens(block)
        if current and current_tokens + tokens > max_tokens:
            flush()
        current.append(block)
        current_tokens += tokens

    if current:
        chunks.append("\n\n".join(current))
    return [c for c in chunks if c.strip()]


def parse_markdown(
    text: str,
    source_path: str,
    version: str,
    chunk_tokens: int = 500,
    overlap: float = 0.15,
    count_tokens: Callable[[str], int] | None = None,
) -> list[Chunk]:
    count_tokens = count_tokens or (lambda s: len(s.split()))
    meta, body = _frontmatter(text)
    if meta.get("draft", "false").lower() == "true":
        return []
    body = SHORTCODE_RE.sub("", body)

    chunks: list[Chunk] = []
    heading_stack: list[tuple[int, str]] = []
    positions = list(HEADING_RE.finditer(_mask_fenced_lines(body)))
    sections: list[tuple[str, str, str]] = []
    if not positions:
        sections.append(("", meta.get("title", ""), body))
    for i, match in enumerate(positions):
        level = len(match.group(1))
        title = match.group(2).strip()
        while heading_stack and heading_stack[-1][0] >= level:
            heading_stack.pop()
        heading_stack.append((level, title))
        start = match.end()
        end = positions[i + 1].start() if i + 1 < len(positions) else len(body)
        heading_path = " > ".join(t for _, t in heading_stack)
        sections.append((heading_path, title, body[start:end].strip()))

    for heading_path, leaf_title, section in sections:
        if not section:
            continue
        for piece in chunk_text(section, chunk_tokens, overlap, count_tokens):
            digest = hashlib.sha256(f"{source_path}:{heading_path}:{piece}".encode()).hexdigest()[:16]
            chunks.append(
                Chunk(
                    id=digest,
                    text=piece,
                    url=_url(source_path, leaf_title),
                    heading=heading_path or meta.get("title", ""),
                    source_path=source_path,
                    version=version,
                )
            )
    return chunks
````

# src/rag/embed.py
from __future__ import annotations

import hashlib

import numpy as np


class Embedder:
    def __init__(self, model_name: str, show_progress: bool = False) -> None:
        from sentence_transformers import SentenceTransformer

        self.model = SentenceTransformer(model_name)
        self.show_progress = show_progress

    def encode(self, texts: list[str]) -> np.ndarray:
        vectors = self.model.encode(
            texts,
            normalize_embeddings=True,
            show_progress_bar=self.show_progress,
            batch_size=64,
        )
        return np.asarray(vectors, dtype=np.float32)


class FakeEmbedder:
    """Deterministic embedder for tests; hashes text into a fixed-size vector."""

    def __init__(self, dim: int = 8) -> None:
        self.dim = dim

    def encode(self, texts: list[str]) -> np.ndarray:
        rows = []
        for text in texts:
            digest = hashlib.sha256(text.encode()).digest()
            rows.append([b / 255.0 for b in digest[: self.dim]])
        return np.asarray(rows, dtype=np.float32)

# src/rag/index.py
from __future__ import annotations

import json
import pickle
from pathlib import Path

import lancedb
import numpy as np
from rank_bm25 import BM25Okapi

from rag.config import Settings
from rag.models import Chunk


def _tokenize(text: str) -> list[str]:
    return [t for t in text.lower().split() if t]


class Index:
    def __init__(self, table, bm25: BM25Okapi, ids: list[str], chunks: dict[str, Chunk], settings: Settings):
        self.table = table
        self.bm25 = bm25
        self.ids = ids
        self.chunks = chunks
        self.settings = settings

    @property
    def count(self) -> int:
        return len(self.ids)

    def get(self, chunk_id: str) -> Chunk:
        return self.chunks[chunk_id]

    def dense_search(self, vector: np.ndarray, k: int) -> list[tuple[str, float]]:
        rows = self.table.search(vector.tolist()).limit(k).to_list()
        return [(row["id"], float(row.get("_distance", 0.0))) for row in rows]

    def bm25_search(self, query: str, k: int) -> list[tuple[str, float]]:
        scores = self.bm25.get_scores(_tokenize(query))
        order = np.argsort(scores)[::-1][:k]
        return [(self.ids[i], float(scores[i])) for i in order]

    def close(self) -> None:
        self.table = None

    @classmethod
    def load(cls, settings: Settings) -> Index:
        index_dir = Path(settings.index_dir)
        db = lancedb.connect(str(index_dir / "lancedb"))
        table = db.open_table("chunks")
        with (index_dir / "bm25.pkl").open("rb") as f:
            payload = pickle.load(f)
        rows = table.to_arrow().to_pylist()
        chunks = {
            row["id"]: Chunk(
                id=row["id"],
                text=row["text"],
                url=row["url"],
                heading=row["heading"],
                source_path=row["source_path"],
                version=row["version"],
            )
            for row in rows
        }
        return cls(table, payload["bm25"], payload["ids"], chunks, settings)


def build_index(chunks: list[Chunk], embedder, settings: Settings) -> Index:
    index_dir = Path(settings.index_dir)
    index_dir.mkdir(parents=True, exist_ok=True)
    vectors = embedder.encode([c.text for c in chunks])
    rows = [
        {
            "id": c.id,
            "text": c.text,
            "url": c.url,
            "heading": c.heading,
            "source_path": c.source_path,
            "version": c.version,
            "vector": vec.tolist(),
        }
        for c, vec in zip(chunks, vectors)
    ]
    db = lancedb.connect(str(index_dir / "lancedb"))
    table = db.create_table("chunks", data=rows, mode="overwrite")

    ids = [c.id for c in chunks]
    bm25 = BM25Okapi([_tokenize(c.text) for c in chunks])
    with (index_dir / "bm25.pkl").open("wb") as f:
        pickle.dump({"ids": ids, "bm25": bm25}, f)

    meta = {
        "chunks": len(chunks),
        "embed_model": settings.embed_model,
        "docs_url": settings.docs_url,
        "chunk_tokens": settings.chunk_tokens,
        "chunk_overlap": settings.chunk_overlap,
    }
    (index_dir / "meta.json").write_text(json.dumps(meta, indent=2))
    return Index(table, bm25, ids, {c.id: c for c in chunks}, settings)

```python
# src/rag/retrieve.py
from __future__ import annotations

import time
from collections import defaultdict

from rag.models import RetrievedChunk


def reciprocal_rank_fusion(rankings: list[list[str]], k: int = 60) -> list[tuple[str, float]]:
    scores: dict[str, float] = defaultdict(float)
    for ranking in rankings:
        for rank, doc_id in enumerate(ranking, start=1):
            scores[doc_id] += 1.0 / (k + rank)
    return sorted(scores.items(), key=lambda item: (-item[1], item[0]))


class CrossEncoderReranker:
    def __init__(self, model_name: str) -> None:
        from sentence_transformers import CrossEncoder

        self.model = CrossEncoder(model_name)

    def score(self, query: str, texts: list[str]) -> list[float]:
        if not texts:
            return []
        return [float(s) for s in self.model.predict([(query, t) for t in texts])]


class Retriever:
    def __init__(
        self,
        index,
        embedder,
        reranker,
        settings=None,
        top_k_context: int | None = None,
        dense_only: bool = False,
        use_reranker: bool = True,
    ):
        self.index = index
        self.embedder = embedder
        self.reranker = reranker
        self.dense_only = dense_only
        self.use_reranker = use_reranker and not dense_only
        self.top_k_dense = getattr(settings, "top_k_dense", 50)
        self.top_k_bm25 = getattr(settings, "top_k_bm25", 50)
        self.top_k_rerank = getattr(settings, "top_k_rerank", 20)
        self.rrf_k = getattr(settings, "rrf_k", 60)
        self.top_k_context = (
            top_k_context
            if top_k_context is not None
            else getattr(settings, "top_k_context", 5)
        )
        self.last_timings: dict[str, int] = {}

    def retrieve(self, question: str, top_k: int | None = None) -> list[RetrievedChunk]:
        limit = self.top_k_context if top_k is None else top_k
        if limit < 1:
            raise ValueError("top_k must be >= 1")
        dense_started = time.perf_counter()
        vector = self.embedder.encode([question])[0]
        dense = self.index.dense_search(vector, self.top_k_dense)
        dense_ms = int((time.perf_counter() - dense_started) * 1000)
        dense_rank = {doc_id: i for i, (doc_id, _) in enumerate(dense, start=1)}
        if self.dense_only:
            self.last_timings = {"dense_ms": dense_ms, "bm25_ms": 0, "rerank_ms": 0}
            return [
                RetrievedChunk(
                    chunk=self.index.get(doc_id),
                    score=score,
                    dense_rank=rank,
                )
                for rank, (doc_id, score) in enumerate(dense[:limit], start=1)
            ]

        bm25_started = time.perf_counter()
        bm25 = self.index.bm25_search(question, self.top_k_bm25)
        bm25_ms = int((time.perf_counter() - bm25_started) * 1000)
        bm25_rank = {doc_id: i for i, (doc_id, _) in enumerate(bm25, start=1)}
        fused = reciprocal_rank_fusion(
            [[doc_id for doc_id, _ in dense], [doc_id for doc_id, _ in bm25]],
            self.rrf_k,
        )
        if not self.use_reranker:
            self.last_timings = {"dense_ms": dense_ms, "bm25_ms": bm25_ms, "rerank_ms": 0}
            return [
                RetrievedChunk(
                    chunk=self.index.get(doc_id),
                    score=score,
                    dense_rank=dense_rank.get(doc_id),
                    bm25_rank=bm25_rank.get(doc_id),
                )
                for doc_id, score in fused[:limit]
            ]

        pool = fused[: max(limit, self.top_k_rerank)]
        candidates = [self.index.get(doc_id) for doc_id, _ in pool]
        rerank_started = time.perf_counter()
        scores = self.reranker.score(question, [c.text for c in candidates])
        rerank_ms = int((time.perf_counter() - rerank_started) * 1000)
        self.last_timings = {"dense_ms": dense_ms, "bm25_ms": bm25_ms, "rerank_ms": rerank_ms}
        ranked = sorted(zip(candidates, scores), key=lambda pair: -pair[1])[:limit]
        return [
            RetrievedChunk(
                chunk=chunk,
                score=score,
                dense_rank=dense_rank.get(chunk.id),
                bm25_rank=bm25_rank.get(chunk.id),
                rerank_score=score,
            )
            for chunk, score in ranked
        ]
```

```python
# src/rag/generate.py
from __future__ import annotations

import re
import time
from dataclasses import dataclass

from rag.config import PROVIDER_DEFAULTS, Settings
from rag.models import Answer, Chunk, Citation, Usage

SYSTEM_PROMPT = """You answer questions about Kubernetes using ONLY the provided documentation excerpts.
Rules:
- Cite every factual claim with [n] matching the excerpt number.
- If the excerpts do not contain the answer, reply exactly: "I don't know based on the provided documentation."
- Do not use outside knowledge.
- Be concise: at most 180 words."""

CITATION_RE = re.compile(r"\[(\d+)\]")

STOPWORDS = {
    "a", "an", "the", "is", "are", "was", "were", "be", "been",
    "what", "how", "why", "when", "where", "which", "who",
    "of", "to", "in", "on", "for", "and", "or",
    "do", "does", "did", "can", "could", "should",
    "i", "you", "it", "this", "that",
}


def _terms(text: str) -> set[str]:
    return {t.lower() for t in re.findall(r"[a-z0-9]+", text)} - STOPWORDS


def _refusal() -> Answer:
    return Answer(
        text="I don't know based on the provided documentation.",
        citations=[],
        usage=Usage(provider="offline", model="extractive"),
        latency_ms=0,
    )


def build_messages(question: str, chunks: list[Chunk]) -> list[dict[str, str]]:
    context = "\n\n".join(
        f"[{i}] {c.url}\nHeading: {c.heading}\n{c.text}" for i, c in enumerate(chunks, start=1)
    )
    return [
        {"role": "system", "content": SYSTEM_PROMPT},
        {"role": "user", "content": f"Documentation excerpts:\n\n{context}\n\nQuestion: {question}"},
    ]


@dataclass(frozen=True)
class Endpoint:
    provider: str
    model: str
    base_url: str
    api_key: str | None


class LLMError(RuntimeError):
    """Raised when every configured provider fails."""


def default_endpoints(settings: Settings) -> list[Endpoint]:
    endpoints = [
        Endpoint(
            provider=settings.llm_provider,
            model=settings.llm_model,
            base_url=settings.llm_base_url,
            api_key=settings.llm_api_key,
        )
    ]
    if settings.llm_fallback_provider:
        defaults = PROVIDER_DEFAULTS[settings.llm_fallback_provider]
        endpoints.append(
            Endpoint(
                provider=settings.llm_fallback_provider,
                model=settings.llm_fallback_model or defaults["model"],
                base_url=settings.llm_fallback_base_url or defaults["base_url"],
                api_key=settings.llm_fallback_api_key,
            )
        )
    return endpoints


def _coerce_usage(raw) -> Usage:
    """Accept a Usage or a legacy token dict from injected clients."""
    if isinstance(raw, Usage):
        return raw
    if isinstance(raw, dict):
        return Usage(
            provider=str(raw.get("provider", "")),
            model=str(raw.get("model", "")),
            prompt_tokens=int(raw.get("prompt_tokens", 0)),
            completion_tokens=int(raw.get("completion_tokens", 0)),
        )
    return Usage()


class LLMClient:
    def __init__(self, settings: Settings, endpoints=None, client_factory=None) -> None:
        self.settings = settings
        self.endpoints = list(endpoints) if endpoints is not None else default_endpoints(settings)
        if not any(endpoint.api_key for endpoint in self.endpoints):
            raise ValueError("no LLM API key is configured for any provider")
        self._factory = client_factory or self._openai_client
        self._clients: dict[str, object] = {}

    @staticmethod
    def _openai_client(endpoint: Endpoint):
        from openai import OpenAI

        return OpenAI(base_url=endpoint.base_url, api_key=endpoint.api_key)

    def _client(self, endpoint: Endpoint):
        if endpoint.provider not in self._clients:
            self._clients[endpoint.provider] = self._factory(endpoint)
        return self._clients[endpoint.provider]

    def complete(self, messages: list[dict[str, str]], max_tokens: int) -> tuple[str, Usage]:
        errors: list[str] = []
        for endpoint in self.endpoints:
            if not endpoint.api_key:
                errors.append(f"{endpoint.provider}: missing API key")
                continue
            try:
                response = self._client(endpoint).chat.completions.create(
                    model=endpoint.model,
                    messages=messages,
                    temperature=0.0,
                    max_tokens=max_tokens,
                )
            except Exception as exc:  # noqa: BLE001 - outage, retired model, rate limit, bad key
                errors.append(f"{endpoint.provider}/{endpoint.model}: {exc}")
                continue
            text = response.choices[0].message.content or ""
            usage = response.usage
            return text.strip(), Usage(
                provider=endpoint.provider,
                model=endpoint.model,
                prompt_tokens=usage.prompt_tokens if usage else 0,
                completion_tokens=usage.completion_tokens if usage else 0,
            )
        raise LLMError("all LLM providers failed: " + "; ".join(errors))


def _citations(text: str, chunks: list[Chunk]) -> list[Citation]:
    seen: set[int] = set()
    result: list[Citation] = []
    for raw in CITATION_RE.findall(text):
        index = int(raw)
        if index in seen or not 1 <= index <= len(chunks):
            continue
        seen.add(index)
        chunk = chunks[index - 1]
        result.append(Citation(index, chunk.url, chunk.heading, chunk.id))
    return sorted(result, key=lambda c: c.id)


def answer_question(question: str, chunks: list[Chunk], llm, settings: Settings) -> Answer:
    if settings.offline:
        return extractive_answer(question, chunks)
    started = time.monotonic()
    text, usage = llm.complete(build_messages(question, chunks), settings.max_answer_tokens)
    return Answer(
        text=text,
        citations=_citations(text, chunks),
        usage=_coerce_usage(usage),
        latency_ms=int((time.monotonic() - started) * 1000),
    )


def extractive_answer(question: str, chunks: list[Chunk]) -> Answer:
    if not chunks:
        return _refusal()
    query = _terms(question)
    best_idx, best = max(
        enumerate(chunks, start=1),
        key=lambda pair: len(query & _terms(pair[1].text)),
    )
    if not best.text.strip():
        return _refusal()
    sentences = re.split(r"(?<=[.!?])\s+", best.text.strip())
    text = " ".join(sentences[:2]).strip() + f" [{best_idx}]"
    return Answer(
        text=text,
        citations=[Citation(best_idx, best.url, best.heading, best.id)],
        usage=Usage(provider="offline", model="extractive"),
        latency_ms=0,
    )
```

# src/rag/api.py
from __future__ import annotations

import time
from pathlib import Path

from fastapi import FastAPI, HTTPException
from fastapi.responses import FileResponse
from fastapi.staticfiles import StaticFiles
from pydantic import BaseModel, Field

from rag.config import Settings
from rag.generate import LLMClient, LLMError, answer_question
from rag.models import Answer
from rag.retrieve import CrossEncoderReranker, Retriever

STATIC_DIR = Path(__file__).resolve().parents[2] / "app" / "static"


class AskRequest(BaseModel):
    question: str = Field(min_length=3, max_length=500)


class CitationOut(BaseModel):
    id: int
    url: str
    heading: str
    chunk_id: str


class AskResponse(BaseModel):
    answer: str
    citations: list[CitationOut]
    retrieval: dict
    usage: dict
    latency_ms: int


def _default_retriever(settings: Settings) -> Retriever:
    from rag.embed import Embedder
    from rag.index import Index

    if not Path(settings.index_dir).is_dir():
        raise FileNotFoundError(
            f"index not found: {settings.index_dir}; run scripts/build_index.py"
        )
    return Retriever(
        Index.load(settings),
        Embedder(settings.embed_model),
        CrossEncoderReranker(settings.rerank_model),
        settings,
        top_k_context=settings.top_k_context,
    )


def create_app(settings: Settings, retriever=None, llm=None) -> FastAPI:
    app = FastAPI(title="Kubernetes Docs RAG")
    app.state.settings = settings
    app.state.retriever = retriever
    app.state.llm = llm
    app.state.error = None

    try:
        if app.state.retriever is None:
            app.state.retriever = _default_retriever(settings)
        if app.state.llm is None and not settings.offline:
            app.state.llm = LLMClient(settings)
    except Exception as exc:  # noqa: BLE001 - keep /health alive when artifacts/keys are missing
        app.state.error = str(exc)

    if STATIC_DIR.exists():
        app.mount("/static", StaticFiles(directory=STATIC_DIR), name="static")

    @app.get("/")
    def root():
        return FileResponse(STATIC_DIR / "index.html")

    @app.get("/health")
    def health():
        return {
            "status": "ok" if app.state.error is None else "degraded",
            "chunks": getattr(app.state.retriever, "index", None).count
            if app.state.retriever is not None and hasattr(app.state.retriever, "index")
            else 0,
            "error": app.state.error,
        }

    @app.post("/ask", response_model=AskResponse)
    def ask(request: AskRequest):
        if app.state.retriever is None or (app.state.llm is None and not settings.offline):
            raise HTTPException(status_code=503, detail=f"service not ready: {app.state.error}")
        started = time.monotonic()
        retrieved = app.state.retriever.retrieve(request.question)
        if not retrieved:
            raise HTTPException(status_code=404, detail="no documents retrieved")
        chunks = [r.chunk for r in retrieved]
        try:
            answer: Answer = answer_question(request.question, chunks, app.state.llm, settings)
        except LLMError as exc:
            raise HTTPException(status_code=503, detail=f"generation unavailable: {exc}") from exc
        return AskResponse(
            answer=answer.text,
            citations=[CitationOut(**c.__dict__) for c in answer.citations],
            retrieval={
                "chunks_used": len(chunks),
                "top_chunk_id": chunks[0].id,
                **getattr(app.state.retriever, "last_timings", {}),
            },
            usage=answer.usage.as_dict(),
            latency_ms=int((time.monotonic() - started) * 1000),
        )

    return app


try:
    app = create_app(Settings.from_env())
except ValueError:
    app = None

# evals/schema.py
from __future__ import annotations

import json
from dataclasses import dataclass
from pathlib import Path

CATEGORIES = {"single-hop", "multi-hop", "troubleshooting", "unanswerable"}
EXPECTED = {"single-hop": 20, "multi-hop": 15, "troubleshooting": 15, "unanswerable": 10}


@dataclass(frozen=True)
class GoldSource:
    url: str
    heading: str


@dataclass(frozen=True)
class EvalQuestion:
    id: str
    split: str
    category: str
    question: str
    reference_answer: str
    gold_sources: list[GoldSource]
    required_facts: list[str]


def load_questions(path: str | Path) -> list[EvalQuestion]:
    rows = []
    for line in Path(path).read_text().splitlines():
        if not line.strip():
            continue
        raw = json.loads(line)
        rows.append(
            EvalQuestion(
                id=raw["id"],
                split=raw["split"],
                category=raw["category"],
                question=raw["question"],
                reference_answer=raw["reference_answer"],
                gold_sources=[GoldSource(**s) for s in raw["gold_sources"]],
                required_facts=raw["required_facts"],
            )
        )
    return rows


def validate_questions(questions: list[EvalQuestion]) -> list[str]:
    errors = []
    ids = [q.id for q in questions]
    if len(ids) != len(set(ids)):
        errors.append("duplicate question ids")
    for split, count in (("dev", 30), ("test", 30)):
        actual = sum(q.split == split for q in questions)
        if actual != count:
            errors.append(f"{split}: expected {count}, got {actual}")
    for category, count in EXPECTED.items():
        actual = sum(q.category == category for q in questions)
        if actual != count:
            errors.append(f"{category}: expected {count}, got {actual}")
    for q in questions:
        if q.category not in CATEGORIES:
            errors.append(f"{q.id}: bad category {q.category}")
        if q.category != "unanswerable" and not q.gold_sources:
            errors.append(f"{q.id}: missing gold sources")
        if q.category != "unanswerable" and not q.required_facts:
            errors.append(f"{q.id}: missing required facts")
    return errors
```

```python
# evals/metrics.py
from __future__ import annotations

import math
import re


def _url_key(url: str) -> str:
    return url.split("#", 1)[0].rstrip("/")


def _keys(urls) -> set[str]:
    return {_url_key(url) for url in urls}


def recall_at_k(retrieved: list[str], gold: set[str], k: int) -> float:
    gold_keys = _keys(gold)
    if not gold_keys:
        return 1.0
    # Count distinct documents: several chunks of the same page are one hit.
    return len(_keys(retrieved[:k]) & gold_keys) / len(gold_keys)


def mrr_at_k(retrieved: list[str], gold: set[str], k: int) -> float:
    gold_keys = _keys(gold)
    for rank, url in enumerate(retrieved[:k], start=1):
        if _url_key(url) in gold_keys:
            return 1.0 / rank
    return 0.0


def ndcg_at_k(retrieved: list[str], gold: set[str], k: int) -> float:
    gold_keys = _keys(gold)
    dcg = 0.0
    seen: set[str] = set()
    for i, url in enumerate(retrieved[:k]):
        key = _url_key(url)
        if key in gold_keys and key not in seen:
            seen.add(key)
            dcg += 1.0 / math.log2(i + 2)
    idcg = sum(1.0 / math.log2(i + 2) for i in range(min(len(gold_keys), k)))
    return dcg / idcg if idcg else 0.0


def citation_precision_recall(cited: list[str], gold: set[str]) -> tuple[float, float]:
    if not cited:
        return 0.0, 0.0
    gold_keys = _keys(gold)
    hits = sum(_url_key(url) in gold_keys for url in cited)
    covered = len(_keys(cited) & gold_keys)
    return hits / len(cited), covered / len(gold_keys) if gold_keys else 0.0


def _normalize(text: str) -> str:
    return re.sub(r"\s+", " ", re.sub(r"[^a-z0-9 ]", " ", text.lower())).strip()


REFUSAL_NORMALIZED = "i don t know based on the provided documentation"


def is_refusal(text: str) -> bool:
    """True when the answer uses the documented refusal sentence."""
    return REFUSAL_NORMALIZED in _normalize(text)


def mean(values) -> float:
    values = list(values)
    return sum(values) / len(values) if values else 0.0


def percentile(values, p: float) -> float:
    """Nearest-rank percentile; returns 0.0 for an empty sample."""
    values = sorted(values)
    if not values:
        return 0.0
    if not 0 <= p <= 100:
        raise ValueError("percentile must be in [0, 100]")
    rank = math.ceil(p / 100 * len(values))
    return float(values[max(0, rank - 1)])


def fact_coverage(answer: str, facts: list[str]) -> float:
    if not facts:
        return 1.0
    normalized = _normalize(answer)
    return sum(_normalize(f) in normalized for f in facts) / len(facts)


def cohen_kappa(a: list[int], b: list[int]) -> float:
    if len(a) != len(b) or not a:
        raise ValueError("label lists must be non-empty and equal length")
    n = len(a)
    observed = sum(x == y for x, y in zip(a, b)) / n
    pa = sum(a) / n
    pb = sum(b) / n
    expected = pa * pb + (1 - pa) * (1 - pb)
    if expected == 1.0:
        return 1.0
    return (observed - expected) / (1 - expected)
```

# evals/validate_questions.py
from __future__ import annotations

import argparse
import re
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
sys.path.insert(0, str(ROOT))

from evals.schema import load_questions, validate_questions

CERTIFICATION_FIELDS = ("Reviewer", "Date", "Notes")


def certification_errors(path: str | Path) -> list[str]:
    """Return missing/blank certification fields for a CERTIFICATION.md file."""
    text = Path(path).read_text(encoding="utf-8")
    errors: list[str] = []
    for field in CERTIFICATION_FIELDS:
        match = re.search(rf"^- {field}:\s*(.*)$", text, re.MULTILINE)
        if match is None or not match.group(1).strip().strip("_- "):
            errors.append(f"certification: {field} is blank")
    return errors


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description="Validate the gold set.")
    parser.add_argument("path", nargs="?", default=str(ROOT / "evals" / "questions.jsonl"))
    parser.add_argument(
        "--require-certified",
        action="store_true",
        help="also require a signed evals/CERTIFICATION.md (used before test-split runs)",
    )
    parser.add_argument(
        "--certification", default=str(ROOT / "evals" / "CERTIFICATION.md")
    )
    args = parser.parse_args(argv)

    questions = load_questions(args.path)
    errors = validate_questions(questions)
    if args.require_certified:
        cert = Path(args.certification)
        if not cert.exists():
            errors.append(f"certification file not found: {cert}")
        else:
            errors.extend(certification_errors(cert))
    if errors:
        print("\n".join(errors))
        return 1
    print(f"ok: {len(questions)} questions")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

# evals/judge.py
from __future__ import annotations

import hashlib
import json
from pathlib import Path

RUBRIC_VERSION = "v1"
# The judge deliberately uses a different model family from the generator so a
# single model cannot grade its own output. Override with --judge-model.
JUDGE_PROVIDER = "gemini"
JUDGE_MODEL = "gemini-2.5-flash"
SCORE_FIELDS = ("correct", "faithful", "citation_support")

JUDGE_PROMPT = """You are grading a RAG answer about Kubernetes documentation.
Return ONLY a JSON object with integer 0/1 fields:
- correct: does the answer cover the reference facts?
- faithful: is every claim supported by the context?
- citation_support: do the cited context items support the claims?
- refusal_correct: 1 if the question is unanswerable and the answer refuses, 0 if it hallucinates, null otherwise.
Also include a one-sentence rationale.
Example: {"correct": 1, "faithful": 1, "citation_support": 1, "refusal_correct": null, "rationale": "Matches the reference."}"""

RETRY_PROMPT = "Your previous reply was not valid. Return only the JSON object, with integer 0/1 values."


def cache_key(question: str, candidate: str, reference: str, context: str) -> str:
    payload = f"{RUBRIC_VERSION}\n{question}\n{candidate}\n{reference}\n{context}"
    return hashlib.sha256(payload.encode()).hexdigest()


def parse_judgement(text: str) -> dict:
    start, end = text.find("{"), text.rfind("}")
    if start < 0 or end <= start:
        raise ValueError("judge response contains no JSON object")
    data = json.loads(text[start : end + 1])
    if not isinstance(data, dict):
        raise TypeError("judge response is not a JSON object")
    result: dict = {}
    for field in SCORE_FIELDS:
        value = data.get(field)
        if value not in (0, 1):
            raise ValueError(f"judge field {field!r} must be 0 or 1")
        result[field] = int(value)
    refusal = data.get("refusal_correct")
    if refusal not in (0, 1, None):
        raise ValueError("judge field 'refusal_correct' must be 0, 1, or null")
    result["refusal_correct"] = refusal
    result["rationale"] = str(data.get("rationale", ""))[:500]
    return result


def invalid_result(error: str) -> dict:
    result: dict = {field: None for field in SCORE_FIELDS}
    result["refusal_correct"] = None
    result["rationale"] = ""
    result["invalid"] = True
    result["error"] = error[:500]
    return result


class Judge:
    def __init__(self, llm, cache_dir: str | Path = "evals/cache") -> None:
        self.llm = llm
        self.cache_dir = Path(cache_dir)
        self.cache_dir.mkdir(parents=True, exist_ok=True)

    def score(
        self, question: str, candidate: str, reference: str, context: str
    ) -> dict:
        key = cache_key(question, candidate, reference, context)
        path = self.cache_dir / f"{key}.json"
        if path.exists():
            return json.loads(path.read_text(encoding="utf-8"))

        messages = [
            {"role": "system", "content": JUDGE_PROMPT},
            {
                "role": "user",
                "content": (
                    f"Question:\n{question}\n\nReference answer:\n{reference}\n\n"
                    f"Candidate answer:\n{candidate}\n\nContext:\n{context}"
                ),
            },
        ]
        errors: list[str] = []
        for attempt in range(2):
            try:
                text, _ = self.llm.complete(messages, 200)
                result = parse_judgement(text)
                path.write_text(json.dumps(result, indent=2), encoding="utf-8")
                return result
            except Exception as exc:  # noqa: BLE001 - invalid output or provider error
                errors.append(f"attempt {attempt + 1}: {exc}")
                messages = messages[:2] + [{"role": "user", "content": RETRY_PROMPT}]
        return invalid_result("; ".join(errors))

# evals/run_eval.py
from __future__ import annotations

import argparse
import json
import os
import sys
from dataclasses import replace
from datetime import UTC, datetime
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
sys.path.insert(0, str(ROOT))
sys.path.insert(0, str(ROOT / "src"))

from evals.judge import JUDGE_MODEL, JUDGE_PROVIDER, Judge
from evals.metrics import (
    citation_precision_recall,
    fact_coverage,
    is_refusal,
    mean,
    mrr_at_k,
    ndcg_at_k,
    percentile,
    recall_at_k,
)
from evals.schema import EvalQuestion, load_questions
from evals.summarize import payload_to_markdown
from evals.validate_questions import certification_errors
from rag.config import PROVIDER_DEFAULTS, Settings

RETRIEVAL_KEYS = ("recall@5", "recall@10", "recall@20", "mrr@10", "ndcg@10")
SMOKE_THRESHOLDS = {"recall@10": 0.5, "ndcg@10": 0.35}


def _retrieval_ms(timings: dict) -> int:
    return int(sum(int(timings.get(key, 0)) for key in ("dense_ms", "bm25_ms", "rerank_ms")))


def _tokens(usage) -> tuple[int, int, str, str]:
    if hasattr(usage, "prompt_tokens"):
        return (
            int(usage.prompt_tokens),
            int(usage.completion_tokens),
            str(usage.provider),
            str(usage.model),
        )
    if isinstance(usage, dict):
        return (
            int(usage.get("prompt_tokens", 0)),
            int(usage.get("completion_tokens", 0)),
            str(usage.get("provider", "")),
            str(usage.get("model", "")),
        )
    return 0, 0, "", ""


def evaluate_question(
    question: EvalQuestion,
    retrieved,
    retrieval_ms: int,
    answer=None,
    judge: Judge | None = None,
) -> dict:
    urls = [item.chunk.url for item in retrieved]
    gold = {source.url for source in question.gold_sources}
    row: dict = {
        "id": question.id,
        "split": question.split,
        "category": question.category,
        "retrieved_urls": urls,
        "retrieval_latency_ms": retrieval_ms,
        "recall@5": recall_at_k(urls, gold, 5),
        "recall@10": recall_at_k(urls, gold, 10),
        "recall@20": recall_at_k(urls, gold, 20),
        "mrr@10": mrr_at_k(urls, gold, 10),
        "ndcg@10": ndcg_at_k(urls, gold, 10),
    }
    if answer is None:
        return row

    cited = [citation.url for citation in answer.citations]
    precision, recall = citation_precision_recall(cited, gold)
    prompt_tokens, completion_tokens, provider, model = _tokens(answer.usage)
    row.update(
        {
            "answer": answer.text,
            "citations": cited,
            "generation_latency_ms": answer.latency_ms,
            "latency_ms": retrieval_ms + answer.latency_ms,
            "fact_coverage": fact_coverage(answer.text, question.required_facts),
            "citation_precision": precision,
            "citation_recall": recall,
            "prompt_tokens": prompt_tokens,
            "completion_tokens": completion_tokens,
            "provider": provider,
            "model": model,
            "refused": is_refusal(answer.text),
        }
    )
    if question.category == "unanswerable":
        row["refusal_correct"] = 1 if row["refused"] else 0
    if judge is not None:
        context = "\n\n".join(item.chunk.text for item in retrieved)
        row["judge"] = judge.score(
            question.question, answer.text, question.reference_answer, context
        )
    return row


def _aggregate(rows: list[dict]) -> dict:
    answerable = [row for row in rows if row["category"] != "unanswerable"]
    unanswerable = [row for row in rows if row["category"] == "unanswerable"]
    metrics: dict = {"n": len(rows)}
    for key in RETRIEVAL_KEYS:
        metrics[key] = mean(row[key] for row in answerable)

    generated = [row for row in answerable if "fact_coverage" in row]
    if generated:
        for key in ("fact_coverage", "citation_precision", "citation_recall"):
            metrics[key] = mean(row[key] for row in generated)
        metrics["over_refusal_rate"] = mean(row["refused"] for row in generated)
        metrics["p95_latency_ms"] = percentile([row["latency_ms"] for row in rows], 95)
        metrics["prompt_tokens"] = sum(row["prompt_tokens"] for row in rows)
        metrics["completion_tokens"] = sum(row["completion_tokens"] for row in rows)
        metrics["billed_usd"] = 0.0
        metrics["cost_usd_per_1k"] = 0.0
        metrics["cost_note"] = "free-tier API; token usage reported, billed cost is $0.00"
    else:
        metrics["p95_latency_ms"] = percentile(
            [row["retrieval_latency_ms"] for row in rows], 95
        )

    scored_refusals = [row for row in unanswerable if "refusal_correct" in row]
    if scored_refusals:
        metrics["refusal_accuracy"] = mean(row["refusal_correct"] for row in scored_refusals)

    judged = [row for row in generated if "judge" in row]
    if judged:
        valid = [row for row in judged if not row["judge"].get("invalid")]
        metrics["judge_n"] = len(valid)
        metrics["judge_invalid"] = len(judged) - len(valid)
        for field in ("correct", "faithful", "citation_support"):
            metrics[f"judge_{field}"] = mean(row["judge"][field] for row in valid) if valid else 0.0
    return metrics


def run_eval(
    questions: list[EvalQuestion],
    retriever,
    answer_fn=None,
    judge: Judge | None = None,
    top_k: int = 20,
) -> dict:
    if top_k < 1:
        raise ValueError("top_k must be >= 1")
    if not questions:
        raise ValueError("no questions selected")
    rows = []
    for question in questions:
        retrieved = retriever.retrieve(question.question, top_k=top_k)
        timings = getattr(retriever, "last_timings", {}) or {}
        answer = None
        if answer_fn is not None:
            answer = answer_fn(question.question, [item.chunk for item in retrieved])
        rows.append(
            evaluate_question(
                question,
                retrieved,
                _retrieval_ms(timings),
                answer=answer,
                judge=judge,
            )
        )
    categories = sorted({row["category"] for row in rows})
    return {
        "generated_at": datetime.now(UTC).isoformat(),
        "top_k": top_k,
        "questions": len(rows),
        "metrics": _aggregate(rows),
        "slices": {category: _aggregate([r for r in rows if r["category"] == category]) for category in categories},
        "rows": rows,
    }


def build_retriever(settings: Settings, mode: str):
    from rag.embed import Embedder
    from rag.index import Index
    from rag.retrieve import CrossEncoderReranker, Retriever

    reranker = (
        CrossEncoderReranker(settings.rerank_model) if mode == "hybrid_rerank" else None
    )
    return Retriever(
        Index.load(settings),
        Embedder(settings.embed_model),
        reranker,
        settings,
        dense_only=mode == "dense",
        use_reranker=mode == "hybrid_rerank",
    )


def build_judge(settings: Settings, model: str, cache_dir: str) -> Judge:
    from rag.generate import LLMClient

    defaults = PROVIDER_DEFAULTS[JUDGE_PROVIDER]
    key = os.getenv(defaults["key_env"])
    if not key:
        raise ValueError(f"{defaults['key_env']} is required for --judge")
    judge_settings = replace(
        settings,
        offline=False,
        llm_provider=JUDGE_PROVIDER,
        llm_model=model,
        llm_base_url=defaults["base_url"],
        llm_api_key=key,
        llm_fallback_provider=None,
        llm_fallback_model=None,
        llm_fallback_base_url=None,
        llm_fallback_api_key=None,
    )
    return Judge(LLMClient(judge_settings), cache_dir=cache_dir)


def threshold_failures(metrics: dict, thresholds: dict | None = None) -> list[str]:
    thresholds = SMOKE_THRESHOLDS if thresholds is None else thresholds
    return [
        f"{key}={metrics.get(key, 0.0):.3f} < {minimum:.2f}"
        for key, minimum in thresholds.items()
        if metrics.get(key, 0.0) < minimum
    ]

        if failures:
            print("smoke thresholds failed: " + ", ".join(failures))
            return 1
    return 0

# evals/calibrate_judge.py
from __future__ import annotations

import argparse
import json
import sys
from datetime import UTC, datetime
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
sys.path.insert(0, str(ROOT))

from evals.judge import RUBRIC_VERSION
from evals.metrics import cohen_kappa, mean

MIN_PAIRS = 20


def load_pairs(labels_path: str | Path, results_path: str | Path) -> tuple[list[int], list[int], list[str]]:
    labels: dict[str, int] = {}
    for line in Path(labels_path).read_text(encoding="utf-8").splitlines():
        if not line.strip():
            continue
        row = json.loads(line)
        value = row.get("human_correct")
        if value in (0, 1):
            labels[row["id"]] = int(value)

    results = {
        row["id"]: row
        for row in json.loads(Path(results_path).read_text(encoding="utf-8"))["rows"]
    }
    human: list[int] = []
    judged: list[int] = []
    missing: list[str] = []
    for question_id, human_value in labels.items():
        judgement = results.get(question_id, {}).get("judge")
        if not judgement or judgement.get("invalid") or judgement.get("correct") not in (0, 1):
            missing.append(question_id)
            continue
        human.append(human_value)
        judged.append(int(judgement["correct"]))
    return human, judged, missing


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description="Calibrate the LLM judge against human labels.")
    parser.add_argument("--labels", default=str(ROOT / "evals" / "calibration.jsonl"))
    parser.add_argument("--results", required=True, help="dev results JSON containing judge scores")
    parser.add_argument("--out", default=str(ROOT / "evals" / "calibration.json"))
    parser.add_argument("--min-kappa", type=float, default=0.75)
    args = parser.parse_args(argv)

    if not Path(args.labels).exists():
        print(f"labels file not found: {args.labels}")
        return 1
    human, judged, missing = load_pairs(args.labels, args.results)
    if len(human) < MIN_PAIRS:
        print(f"need at least {MIN_PAIRS} paired labels, got {len(human)}")
        return 1

    kappa = cohen_kappa(human, judged)
    payload = {
        "generated_at": datetime.now(UTC).isoformat(),
        "rubric_version": RUBRIC_VERSION,
        "n": len(human),
        "agreement": mean(int(a == b) for a, b in zip(human, judged)),
        "kappa": kappa,
        "gate_pass": kappa >= args.min_kappa,
        "min_kappa": args.min_kappa,
        "missing_judgements": missing,
    }
    Path(args.out).write_text(json.dumps(payload, indent=2), encoding="utf-8")
    print(
        f"n={payload['n']} agreement={payload['agreement']:.3f} "
        f"kappa={kappa:.3f} gate={'pass' if payload['gate_pass'] else 'fail'}"
    )
    if missing:
        print(f"missing or invalid judgements: {', '.join(missing)}")
    return 0 if payload["gate_pass"] else 1


if __name__ == "__main__":
    raise SystemExit(main())

```python
# evals/summarize.py
from __future__ import annotations

import argparse
import json
from pathlib import Path

COLUMNS = (
    ("config", "config"),
    ("n", "n"),
    ("recall@5", "R@5"),
    ("recall@10", "R@10"),
    ("recall@20", "R@20"),
    ("mrr@10", "MRR@10"),
    ("ndcg@10", "nDCG@10"),
    ("citation_precision", "cit-P"),
    ("citation_recall", "cit-R"),
    ("fact_coverage", "fact-cov"),
    ("refusal_accuracy", "refusal"),
    ("p95_latency_ms", "p95 ms"),
    ("cost_usd_per_1k", "$/1k"),
)


def _fmt(value) -> str:
    if value is None:
        return "—"
    if isinstance(value, float):
        return f"{value:.3f}"
    return str(value)


def format_table(rows: list[tuple[str, dict]]) -> str:
    header = "| " + " | ".join(label for _, label in COLUMNS) + " |"
    separator = "|" + "|".join("---:" for _ in COLUMNS) + "|"
    lines = [header, separator]
    for name, payload in rows:
        metrics = payload.get("metrics", {})
        cells = [name, str(payload.get("questions", metrics.get("n", "")))]
        for key, _ in COLUMNS[2:]:
            cells.append(_fmt(metrics.get(key)))
        lines.append("| " + " | ".join(cells) + " |")
    return "\n".join(lines)


def payload_to_markdown(name: str, payload: dict) -> str:
    return format_table([(name, payload)])


def summarize(paths: list[str | Path]) -> str:
    rows = []
    for path in paths:
        payload = json.loads(Path(path).read_text(encoding="utf-8"))
        rows.append((Path(path).stem, payload))
    return format_table(rows)


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description="Render eval results JSON as a markdown table.")
    parser.add_argument("paths", nargs="+", help="result JSON files")
    args = parser.parse_args(argv)
    print(summarize(args.paths))
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```
