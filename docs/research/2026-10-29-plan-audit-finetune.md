> **Historical record:** this document preserves earlier plans, decisions, or observations. See [current status and next milestones](../STATUS.md) for the maintained project status.


Date: 2026-10-29
Scope: `docs/superpowers/plans/2026-10-29-finetune-function-calling.md` (1,763 lines at audit time) and `docs/superpowers/specs/2026-10-29-llm-portfolio-design.md` (301 lines at audit time), on branch `feat/rag-eval`.
Status: docs-only reconciliation. The plan has never been executed; `projects/02-finetune-function-calling/` does not exist yet, so every fix below is a documentation change, not a code change. No commit was made.

## Why this audit exists

The finetune plan was written before the RAG build started. The RAG build then changed one external fact (Groq retired its default model) and produced conventions the finetune project should match (provider fallback, cost accounting, certification/CI discipline). This memo records each defect found in the finetune plan and design spec, the line reference at audit time, the severity, the resolution applied, and the residual risk that remains after the edit. It is the companion to the RAG audit memo; it does not modify the RAG plan or RAG audit memo.

## Residual limitations (not fixable in docs)

1. **Free-tier churn.** The plan now fails closed and documents a fallback, but Groq/Gemini quotas and served model IDs can change again; the first API run is the real gate.
2. **Split is schema-disjoint, not distribution-disjoint.** Normalized hashing removes the description-noise leak, but enum/format/required differences are ignored (conservative) and paraphrased duplicates can still cross splits (documented).
3. **Dedupe is lexical, not semantic.** `dedupe_near` catches case/whitespace/punctuation variants only.
4. **Forgetting check is coarse.** 200 MMLU rows, 8-token greedy decode, anchored parser; a delta is a signal, not a benchmark.
5. **Cost is a free-tier number.** The `$0` basis is explicit; paid-tier cost requires updating `PRICING` with the provider's current price card.
6. **Human gates remain.** Dataset pin review, Colab/GPU runs, HF Hub publish, LICENSE choice, Project 1 artifact availability for the root README, and certifying any published number.
7. **No executable verification of the unexecuted plan.** The code blocks are still prose until Project 2 starts; the first execution should run the test-count expectations (`15`, `4`, `2`, `2`, `8`, `2`, `3`, `1`) as a real signal.

## Human gates introduced or reinforced by this audit
